# Before Presentation Checklist

## Content

- [ ] ตอบ WHO ได้พร้อม IP table
- [ ] ตอบ WHEN ได้พร้อม incident windows
- [ ] ตอบ HOW ได้พร้อม attack patterns
- [ ] ตอบ TELL PEOPLE ได้ด้วย dashboard
- [ ] ตอบ HIDDEN BONUS ได้ หรือบอก candidate/confidence ชัด

## Evidence

- [ ] ทุก attacker IP มี evidence lines
- [ ] ทุก incident window มี metric รองรับ
- [ ] ทุก attack pattern มีตัวอย่าง request
- [ ] hidden bonus มี source/context

## Limitations

- [ ] บอกว่าไม่มี response time ถ้าอ้างเรื่องหน่วง
- [ ] บอกว่าไม่มี user-agent
- [ ] บอกว่า scoring เป็น explainable heuristic ไม่ใช่ความจริง absolute

## Demo

- [ ] Dashboard เปิดได้
- [ ] กราฟ timeline อ่านออก
- [ ] attacker table sort ได้/เห็นง่าย
- [ ] evidence table ไม่รกเกินไป

## Q&A

- [ ] เตรียมตอบ false positive
- [ ] เตรียมตอบ scoring threshold
- [ ] เตรียมตอบ why not manual
- [ ] เตรียมตอบ hidden bonus confidence
