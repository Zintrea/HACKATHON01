Limitations we should say out loud

  • Latency is available as field 6 (latency_ms) → slowdown can be backed by measured latency.
  • No User-Agent → cannot identify tools like sqlmap/curl from UA.
  • No request body → payloads are visible only in endpoint/path/query.
  • Scores are explainable heuristics; final claims cite evidence rows.
